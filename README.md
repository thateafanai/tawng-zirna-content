# Ṭawng Zirna content

Content for the Ṭawng Zirna language-learning app by BABFO. The app reads these
files when a learner taps **More → Check for updates**. It only downloads; it
never sends anything.

Published at <https://thateafanai.github.io/tawng-zirna-content/> (GitHub Pages).

## Files

| File | What it is |
|---|---|
| `index.json` | The list of packs and their versions, **in import order** (the word bank before the course). The app reads this first. |
| `packs/core.json` | The word bank (dictionary): every word and phrase in English, Hindi and Mizo (pack `core`). Generated from Thatea's Excel list by the app's `tool/course/build_course.py`. |
| `packs/course-year.json` | "Language in a Year": the lesson plan only (12 months of 24 lesson days, each a list of word-bank uids). Generated by the same tool. |
| `packs/community-<code>.json` | Approved community words for one language, e.g. `community-nnp` (Wancho): they fill the course and the dictionary for that language. Only learners of that language download it. |
| `spelling/nnp.json` | Wancho spelling list for typing suggestions: 24,073 words with how often each is used, from the Otsao Baibel (Bible Society of India, 2012). Words only, never verses; names left out. Only Wancho learners download it. |

## Spelling lists

Made on the computer with the app's `tool/make_spelling_list.py` (see the
instructions at the top of that file). To update one, run it with
`--version` raised by 1, raise the `version` in `index.json` too, check, push.

## The word bank and the course

Both are generated, never edited by hand. From the app's project folder:

    py -X utf8 tool/course/build_course.py "D:/Dev/assets/tawng-zirna/Master_Spoken_App_Data.xlsx" --core-version N --course-version M

Raise the version of each pack that changed (words corrected: core; lessons
reordered: course), copy `assets/data/core.json` → `packs/core.json` and
`assets/data/course_year.json` → `packs/course-year.json`, update index.json,
check, push.

## Community packs (a language's steward)

1. Put the files learners sent ("Share with BABFO") in one folder.
2. `py -X utf8 tool/community/merge_contributions.py nnp <folder>` writes
   `Community_nnp_review.xlsx`: one row per meaning with every answer sent.
   Fill "Approved" and set "Include" to yes or no (yellow rows need a decision).
3. `py -X utf8 tool/community/build_community_pack.py <review.xlsx> --lang nnp --name Wancho --version N --out ../tawng-zirna-content/packs/community-nnp.json`
4. Add the printed entry to index.json (after the core and course packs), check, push.

## Publishing an update

1. Edit the pack (add or correct entries, or list removed uids in `deleted`).
2. Raise the pack's `version` by 1, **in the pack and in `index.json`**.
3. Check it, from the app's project folder:
   `dart run tool/check_content.dart ../tawng-zirna-content`
4. Commit and push. Phones get it the next time they check for updates.

## Rules

- **Never change or reuse a published `uid`.** Remove an entry by listing its uid
  in `deleted`.
- A pack only changes what it brought itself: a community pack adds its language
  to an entry but never changes the core pack's English, Hindi or Mizo.
- A learner's own words always win over pack content on their phone.
- Mizo marked `"status": "draft"` has not been checked by a native speaker yet.
- A community pack's `language` field in `index.json` must be the language's
  shared code (ISO 639-3, e.g. `nnp` for Wancho).
